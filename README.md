# Sales Data Analysis (DEPI Python Mini-Project)

## Overview
Analysis of retail sales data: cleaning, feature engineering, EDA, KPIs.

## Tools
Python, Pandas, Matplotlib, Seaborn, Jupyter

## What the notebook does
- Reads Excel/CSV files with OOP reader classes and error handling
- Cleans the data (duplicates, missing values, invalid IDs, outliers)
- Creates features: Shipping Days, Profit Margin, Sales Performance Category
- EDA with 20 charts, then KPI report and exports

## Key results
- Total sales: 1,122,111.83
- Total profit: 393,700.51 (35.09% margin)
- 488 orders; Standard Class is the most common ship mode
- Average shipping time: 4.01 days
